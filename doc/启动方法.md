# 设置环境

```bash
cd /home/rainple/nav_test

# 或者直接用统一环境脚本（推荐，它还设置 domain / Gazebo partition / 渲染模式）
source log/accept_env.sh
```

# 终端A：启动仿真

```bash
# 终端 A：仿真（含世界、机器人、桥、真值定位、速度选择器）
ros2 launch pb_vehicle_adapter pb_vehicle_sim.launch.py \
  world_name:=rmuc2026_field control_source:=meshnav \
  start_gazebo_gui:=True start_rviz:=False \
  spawn_x:=-1.90 spawn_y:=5.95 spawn_z:=0.25 spawn_yaw_deg:=0 \
  spawn_rendering_sensors:=True        # 无 GPU 时改 False（软件渲染会把 RTF 压到 ~0.06）
```

# 终端B：启动mesh_nav

```bash
# 终端 B：导航栈（start_sim:=False 复用 A 的仿真；会切 control_source）
ros2 launch pb_vehicle_adapter pb_meshnav.launch.py \
  start_sim:=False start_rviz:=True
```

默认使用隧道入口去凸起后的新缓存 `meshnav_demo_ws/rmuc2026_pb_tunnel_relief_removed.h5`；不要显式传入旧的 `rmuc2026_pb_low_navigation.h5`，否则仍会看到旧地图。修改 STL 后要完整重启 Gazebo 和导航节点。
